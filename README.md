# Evaluación de Codesarrollo.

## Primera parte (Base de datos)
Archivos:
- init.sql: crea la base de datos junto con sus tablas.
- InsertarDatosPrueba.sql: inserta los datos de prueba para probar si la consulta funciona.
- ConsultaMorosidad.sql: contiene la resolución a la consulta que se pide en el literal 1.

## Segunda parte (Codigo en C# literales 2-7)
### Formularios
- GridView de los estudiantes.
- Botones para ordenar por nombres de manera ascendente y descendente.
- Boton para agregar un nuevo alumno.
- Lista de estudiantes activos.
- ComboBox que se actualiza al seleccionar algun alumno activo de la lista.
- Descripción del estudiante seleccionado.
